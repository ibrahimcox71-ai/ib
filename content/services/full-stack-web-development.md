## What you get

A website that is **an asset, not a subscription**. Hand-coded pages load fast because
there is no framework runtime to download, rank well because semantic HTML and metadata
are done right from the start, and stay maintainable because the code is clean vanilla
JavaScript that any developer can pick up.

## How is the site built?

1. **Research first** — goals, audience, competitors and the one action each page must drive.
2. **Structure & design** — page hierarchy, wireframes and a distinctive visual system.
3. **Build** — semantic HTML, modern CSS, vanilla JavaScript, optimized images.
4. **Harden & launch** — accessibility checks, performance budget, security headers, SEO schema.

## Who is this for?

Founders and small brands who have outgrown templates and want a site that
loads in under two seconds and turns traffic into inquiries.
